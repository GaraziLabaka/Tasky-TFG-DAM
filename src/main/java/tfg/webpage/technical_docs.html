Technical Documentation

This is the technical documentation for Tasky. Here you will find information about the architecture and implementation details.

Architecture

Tasky is built on JavaFX and utilizes modern Java programming practices. It also uses an external SMTP server (MailJet) for sending mail notifications. Maven and Hibernate are used to enable data automatization and persistence, MySQL serves as the main database.

GitHub Repository

For more detailed technical information, including the source code, please visit our GitHub repository

Code execution

To run the Tasky application, follow these steps:

  1. Ensure you have Java JDK 11 or later installed.
  2. Clone the GitHub repository.
  3. Open the project in your preferred IDE.
  4. Build the project using Maven.
  5. Go to the terminal and run mvn exec:java.
